# Pacote: documentação + radar de notícias do Blog do CITi

Copie para a raiz do repositório `blog-citi`:

- `docs/` → documentação completa (comece por `docs/README.md`)
- `scripts/radar/` → radar automático de notícias (TypeScript)
- `radar/` → pasta onde o radar grava relatórios e rascunhos
- `.github/workflows/radar-semanal.yml` → agendamento semanal no GitHub Actions

Depois siga a seção "Instalação" de `docs/03-RADAR-AUTOMATICO.md`.
